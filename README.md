# Modenov Randomize It!

Забавный генератор коротких абсурдных сказок на русском языке. Он собирает одно предложение из пяти случайно выбранных фрагментов: персонажа, места, наречия, глагола и объекта действия.

## Запуск

Откройте `index.html` в современном браузере. Сборка, сервер и установка зависимостей не нужны.

## Возможности

- Пять встроенных списков по 50 вариантов каждый.
- Генерация новой сказки по кнопке.
- Редактирование списков прямо в браузере; изменения хранятся в `sessionStorage` текущей вкладки и сбрасываются после её закрытия.
- Импорт `.txt` для каждого списка: один вариант на строку. Импорт заменяет содержимое соответствующего поля; нажмите «Сохранить списки», чтобы применить.
- Светлая и тёмная темы, настройка действует до закрытия вкладки.
- Копирование результата в буфер обмена.

Для генерации случайно комбинируются грамматически согласованные формы; поскольку слова выбираются независимо, смысловые сочетания намеренно бывают нелепыми.

## Структура

- `index.html` — разметка приложения.
- `styles.css` — оформление и адаптация для мобильных экранов.
- `app.js` — списки слов и логика генератора, редактора, импорта и тем.
